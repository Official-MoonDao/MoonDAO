Eighteen directions. The second set has a pulse.

The first ten were too well-behaved — professional, and interchangeable. Award-winning sites that still feel like someone made them usually have one irregularity: a voice, a face, a physical object, a second hand in the margin. 11–18 try that, without giving up the restraint.
